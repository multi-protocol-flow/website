Plugin Marketplace

7 core protocols ship in the MPE binary. Everything else is a plugin — install with one command.

Install a Plugin

From the desktop app, open Settings → Plugin Market. From the CLI:

mpe plugin install <name> --registry https://multi-protocol-flow.github.io/mpe-plugin-registry

Or set MPE_PLUGIN_REGISTRY once — then mpe plugin install <name> works without flags.
