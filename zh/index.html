MCP 智能体服务可视化调试与评估

WebSocket & SSE 实时长连接调试

开箱即用支持持久化 WebSocket 会话与 Server-Sent Events 流式事件监听。支持消息自动匹配、流式缓冲区消费与全双工消息收发验证。

TCP & UDP 原始套接字工作流

支持原生二进制 Hex、ASCII 文本或 JSON 格式的 TCP/UDP 连接、数据收发与套接字管理。满足物联网、音视频信令与私有网关协议测试需求。

GraphQL 模式内省与查询订阅

自动内省 GraphQL 架构定义、通过图形化字段树浏览字段，轻松编排复杂的 Query、Mutation 与基于 WebSocket 的 Subscription 订阅流。

动态变量提取与条件分支路由

支持从上游协议响应中通过 JSONPath、正则或脚本提取变量，并在后续步骤中无缝引用（{{variable}}）。通过条件节点实现复杂业务分支流转。

常见问题解答

了解关于 MPE Flow 架构、协议支持与自动化部署的一切信息。

什么是 MPE Flow？

MPE Flow (Multi-Protocol Flow Executor) 是一款基于 Rust 和 Tauri 构建的高性能跨协议工作流编排与集成测试引擎。它允许开发者通过可视化画布轻松编排跨 HTTP、WebSocket、TCP、UDP、SSE、GraphQL、Kafka 与 MCP 的复杂场景，提供桌面端 GUI 与独立无头 CLI。

内置原生支持哪些协议，哪些协议通过插件扩展？

MPE Flow 单一二进制中原生内置了 7 种核心协议与节点：HTTP/HTTPS、WebSocket、TCP、UDP、SSE (服务端推送事件)、GraphQL、以及 Script/Assertion（脚本与断言）节点。Kafka、MCP、gRPC、Redis、MongoDB、SMTP、IMAP 等其他协议则通过一键侧边进程插件生态提供支持。

MPE Flow 与 Postman 或 JMeter 相比有什么优势？

不同于专注于 HTTP 请求的 Postman，MPE Flow 对长连接与有状态协议（TCP、WebSocket、SSE 流、Kafka 消息队列、MCP 智能体工具）提供一等公民的原生支持，并具备图节点可视化流转、分支路由、变量自动提取、强类型断言及超高并发压测能力，资源占用极低。

MPE Flow 可以集成到 CI/CD 流水线中吗？

完全可以。MPE Flow 采用单二进制双模式架构，内置独立的 mpe CLI 命令。在 GitHub Actions、GitLab CI、Jenkins 或 Docker 容器中直接执行 mpe run flow.mpf --report json 即可无 GUI 依赖高速运行流程并输出结构化测试报告。

MPE Flow 是开源免费的吗？

是的，MPE Flow 采用宽松的 MIT 开源协议，代码完全托管在 GitHub：github.com/multi-protocol-flow。
